# BlogCMS 🚀

A simple and modern Content Management System (CMS) designed for blogs, built with **PHP** and **MySQL**.

## ✨ Features
* **Modern UI:** Sleek and responsive login and signup pages with a clean user experience.
* **User Management:** Secure authentication system using PHP `sessions` and password hashing.
* **Professional Dashboard:** A dual-layered navigation bar for easy access to management tools.
* **Article Management:** Functionality to add or delete articles and manage user comments.
* **Role-Based Access:** Distinction between standard Users and Administrators for enhanced security.

## 🛠 Tech Stack
* **Frontend:** HTML5, CSS3 (Modern Green/Purple theme).
* **Backend:** PHP (using PDO for secure database interactions).
* **Database:** MySQL.
* **Icons:** Font Awesome.
